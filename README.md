# Thanks for checking out my shaders!

This project showcases shaders I've written in GLSL and implemented in C++ using a custom game engine (MGE). 

#

Terrain using 4 textures: grass, sand, stone and snow in combination with a height and splat map. | Moving regular and radial checkerboard patterns. | Specular lighting with distance attenuation implemented and adjustable surface roughness.
